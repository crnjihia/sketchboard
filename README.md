## Features

- 📐 **Rectangle drawing & selection** – draw and select rectangles on the canvas.
- 🗒️ **Sticky notes UI** – draggable, resizable notes with editable content.
- ✍️ **Freehand drawing & text notes** – sketch strokes and add inline text annotations.
- 🎨 **Kanga‑cloth aesthetic** – playful colour palette inspired by Kenyan designs.
- 🔁 **Real‑time collaboration** – powered by Yjs CRDT and a WebSocket server (upcoming).
- 📦 **Docker‑compose dev environment** – easy local setup.
